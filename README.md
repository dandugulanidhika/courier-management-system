Courier Delivery Management System
A Java-based object-oriented application designed to model and manage courier shipments, calculate standard and express pricing schedules, handle delivery refunds, and maintain parcel tracking statistics.

📌 Project Overview
The Courier Delivery Management System processes parcel shipping requests by applying standard distance and weight metrics alongside optional insurance coverage and express surcharges. Built using core Object-Oriented Programming (OOP) principles—including encapsulation, inheritance, method overloading, and overriding—the system enforces dynamic fee structures and automated parcel counting.
